Interpretation: Die stark belegten Zonen sind bereits **Mainthread/Single-Core-nah**, obwohl die Gesamt-CPU noch Reserve hat. Gesamt-CPU darf daher nie allein über vertikale Skalierung entscheiden.

### Performance / Vertical Scaling

Manager-Einstufung: **Single-Core limitiert, Host hat Parallelreserve**.

Das ist wichtig für den Dell R720: eine zweite CPU erhöht hauptsächlich die Zahl parallel sinnvoll laufender Prozesse; eine einzelne Zone wird dadurch nicht automatisch doppelt so schnell. Für weniger, stärkere Zonen ist hohe Pro-Kern-Leistung wichtiger.

Kritisch: diese Objektklassen teilen einen 16-Bit-Handle-Raum. Eine Änderung wie `ShineMob 8000 -> 12000` darf nicht isoliert erfolgen; nachfolgende Basen/Ranges und alle abhängigen Checks müssen atomar angepasst werden.

## 7. Diagnose / Logs / PDB

- Logsuche ist rekursiv innerhalb der Serviceordner.
- Unterstützte Logtypen umfassen u.a. `.txt`, `.log`, `.err`, `.out`, `.trace`, `.dbg`.
- Live-Timeline + Vollanalyse korrelieren Service/PID, Ports, WM Readiness, Zone Start/Stop, Reconnects, Windows Event Log und Diagnosecodes.
- PDB-Symbolindexierung verwendet `llvm-pdbutil`.
- Frühere Diagnosecode-Kollision ist in 0.3.4 behoben: `NG-ZONE-0020` bleibt NPC-Pool; erfolgreiche Runtime-Recovery ist `NG-RUNTIME-0002`.

## 8. Historischer Zone03-/WM-Befund

- Zone03 beendet sich beim normalen Startup, funktioniert später nach manuellem Start.
- WorldManager braucht deutlich länger bis `SUCCESSED RUNNING SERVER` als das alte Startscript wartet.
- PDB beweist Support für `NC_GUILD_GUILDWARSTATUS_REQ` (`dep=29 cmd=149`, Opcode `0x7495`).
- `SERVER_ID_UNKNOWN` / Parserfehler passen zur Startup-/Readiness-Race, nicht zu einem fehlenden Opcode.
- Smart Start wartet deshalb auf WM-Status, internen Port, aktuellen Readiness-Marker und startet Zonen gestaffelt.
- Zone05 funktioniert; keinen Zone0–Zone4-Hardcode annehmen.

## 9. Hardwarestrategie

Test-PC: hohe Pro-Kern-Leistung, aber nur 16 GB RAM.

Zusätzlicher Server: Dell PowerEdge R720, derzeit eine 10-Core-CPU mit ca. 2,5 GHz und 128 GB RAM; Ausbau auf zwei CPUs möglich.

Bisherige R720-Richtung für Fiesta: `2 × Xeon E5-2667 v2`, sofern exaktes Chassis, BIOS, Kühlung und TDP-Kompatibilität passen. Grund: höhere Pro-Kern-Leistung plus genug physische Kerne für getrennte Zone-/WM-Prozesse.
